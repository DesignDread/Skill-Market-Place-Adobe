# Engagement-Audit Detailed Checklist

## Orientation
- [ ] A plain-text sentence within the first ~600 characters of visible body text states what the brand/product is and does

## Action
- [ ] At least one clear, action-oriented CTA (button/link) present
- [ ] Not more than a handful of equally-weighted CTAs with no clear primary one

## Navigation
- [ ] Internal link sample contains no broken (4xx/unreachable) links
- [ ] Key-intent pages (pricing, contact) reachable within a small number of clicks from the homepage, where present in the sampled pages

## Accessibility / mobile
- [ ] `<meta name="viewport">` present

## Trust
- [ ] A findable contact method (email/phone pattern) or an about/privacy/terms link present in page text

## Known limitations
This skill approximates "first screen" with a fixed character count of the linearized body text, which is a rough proxy for above-the-fold content and does not account for CSS layout. It does not measure actual page-load performance beyond what the render step (in reach-and-read) already captures.
